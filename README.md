# sop-writer

Custom WordPress theme for **SOP Writer Prakash** is available at:

`wp-content/themes/sop-writer-prakash`

## How to use

1. Copy the `sop-writer-prakash` folder into your WordPress installation under `wp-content/themes/`.
2. Go to **WordPress Admin → Appearance → Themes** and activate **SOP Writer Prakash**.
3. Set your homepage:
   - **Settings → Reading → Your homepage displays → A static page**
   - Select a page as homepage (or keep default front-page template behavior).
